Bugs / issues found

BUG-01 — .cre-t-146-top-content1-mobile block never renders at any viewportLOW

This block (classification text + dropdown chevron, mirroring the PIG SWF135/SWF139 template) is meant to be the mobile-only alternate to the desktop score line. Its own @media (max-width: 767px) rule sets it to display: none, so the parent hide wins over child overrides declared in the same media query (e.g. the chevron's display: flex) — the block never renders at any viewport, on any browser.

No visible defect for the end user: the classification text ("Exceptional", "Very Good", etc.) is still shown via .cre-t-146-top-content1-text, which is present and unaffected on both desktop and mobile. This appears to be dead code/CSS left over from the SWF135/139 template this test was built from. Recommend either removing the unused block + its markup, or fixing the display: none if a distinct mobile rendering was actually intended.
